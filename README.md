# 🍔 Food Finder UI/UX Redesign

A responsive UI/UX redesign case study of the **Food Finder** application created in **Figma**. This project focuses on improving the user experience through a modern interface, responsive layouts, accessibility enhancements, and an interactive prototype.

---

## 📖 Project Overview

The goal of this project was to redesign an existing food ordering application by identifying usability issues and creating a cleaner, more intuitive, and user-friendly interface. The redesign follows user-centered design principles and provides a consistent experience across desktop, tablet, and mobile devices.

---

## 🎯 Objectives

- Improve the overall user experience
- Create a clean and modern interface
- Enhance navigation and usability
- Design responsive layouts for multiple devices
- Apply basic WCAG accessibility principles
- Develop an interactive prototype in Figma

---

- **Figma**
- Auto Layout

- Interactive Prototype
- Stark / Figma Contrast Checker

## 📐 Responsive Design

The interface has been designed for three screen sizes:

- **Desktop:** 1440 × 1024
- **Tablet:** 768 × 1024
- **Mobile:** 390 × 844

---

## ♿ Accessibility

The redesign follows basic accessibility practices by using readable typography, sufficient color contrast, consistent spacing, and clear navigation to provide a better experience for all users.

---

## 🚀 Prototype

The interactive prototype demonstrates the complete user journey:
